## 5) Define copyright and answer the following questions about it: 

- Do you have to apply to have your work copyrighted? 

No - copyright protection is automatic the moment you publish any media that meets the criteria (type, originality, effort etc) 

- What type of media does it apply to? 

- Literary (written) work 

- Sheet music or musical recording 

- Film 

- Radio or TV broadcast 

- Art 

- Computer program 

- How long does copyright last? 

For the author’s lifetime, plus an additional 70 years 




- Would someone that produces something in country A, also automatically be granted copyright protection in country B? In theory, yes - 181 of 195 countries are signed up to the Berne Convention for the protection of copyright. However, in reality, copyright infringement issues may not actually be enforced in many situations (due to time/money/lack of desire to prosecute) etc 

- Does someone working for a company automatically have copyright for work they produced at work? 

In this case, the company decides whether they or the employee claims copyright - afterall, if they are paying the employee to work on something, the company will want to be the owner of the intellectural property 

- 6) Give 2 moral reasons why copyright laws should exist 

- Creation can take time, effort, expertise and money 

- Creation also requires original thinking 

- Hence copyright holder should be able to earn money from their work, without others quickly copying it 

- It’s also unfair that people who copy original can make money, without any payment to original creator

Shareware: full features available during trial period, but trial will end after a certain time - e.g. 1 month for Microsoft Office 

Freeware: software free forever, but the free version contains less features than the full version - e.g. Adobe Reader, many websites like YouTube, PseudocodePro etc 

8) Define the terms “open source” and “free” software (note: the “free” here isn’t necessarily referring to the price) Open source: 

- Source code is available to public, free of charge 

- Attitude is that people will contribute their own changes/features 

- User is free to use, modify, copy or distribute it in accordance to terms of license 

Free software: 

- The ‘free’ more refers to the freedom a user has – they are free to use the software in any way they want 

- There may be a small fee to cover distributing/hosting costs 

- Is also open source 

- ‘Copyleft’ – the condition that a user can modify and distribute their version, though they have to use the SAME license/conditions as the original 

- 9) Give 3 benefits of a company buying a commercial software product, rather than using a free-alternative 

- Likely to be long-term, stable and have required features the company desires 

- Software may have been created to be used in conjunction with already installed software - e.g. Photoshop integrates well with Premiere Pro & After Effects 

- Continuous support, detailed documentation andiled maintenance may be provided 

- Users with license may be able to have their suggestions implemented 

- Might adhere to regulations more than free alternatives (particularly if used for financial/medical/sensitive data etc) 

10) Give 3 advantages of a company using a community-driven open-source project compared to close-source software developed by a private company 

- Full functionality might be available for free/nominal cost 

- If full functionality not provided, user can download and change source code to meet their requirements 

- Might be more secure - since code can be viewed by anyone, hence more bugs might be reported and fixed 

- Collaborative efforts can produce large, complex projects - e.g. Linux, Apache etc 

- Future developments and maintainence provided by users of software, rather than commercial company (who may stop providing support if it’s not financially-viable) 

## 11) Give a simple definition for the term AI 

“AI concerns the use of a computer or computer-controlled device to perform tasks normally associated with intelligent behaviour by humans.”

Linguistics - understanding input words/audio and responding in a way that makes semantic and grammatical sense - e.g. LLMs Perception - having awareness of the objects in its surroundings - e.g. self-driving car Reasoning - evaluating potential approaches to solve the problem and deciding which it thinks is the best approach - e.g. coding helpers 

Learning - improving its performance over time/with more data - e.g. image classification 

13) A few ways an AI can solve problems are by brute force, expert systems and machine learning/neural networks - explain what these terms mean and state which of these approaches the following scenarios would probably use: 

Brute force: try all/a large number of combinations, calculate their score/effectiveness, then chose the highest scoring option Expert system: series of rules are programmed into a machine by a human expert - the expert system can then apply these rules to new input data to arrive at an output 

Machine learning: a model is trained based on huge amounts of input data and tries to learn patterns in the data that result in given outputs - when in production, the system should be able to be given input, run it through the model and produce sensible output Neural networks: a specific type of machine learning model comprised of an input layer, usually many hidden layers and an output layer. The hidden layer contains nodes with various weightings (numbers between 0-1) - backtracking is used to modify these weights so they produce more accurate predictions 

a) A computer that simulates chess by trying billions of possible moves and choosing the best one Brute force 

b) A computer that understands the rules of chess and tries to make sensible logical moves based on these rules Expert system 

c) A chatbot like ChatGPT Neural network 

d) The ‘travelling salesman’ problem - i.e. a salesman/delivery driver has to visit n different cities and wants to find the shortest route that will allow them to visit all of them Brute force 

e) Image-classifiers - e.g. saying whether an object is a cat or dog, whether a scan includes a tumour or not etc Machine learning/neural network 

f) Self-driving cars Machine learning/neural network 

14) List 3 ways AI/automation/robots could benefit society and 3 negative effects of them 

Advantages: 

- Increased efficiency - e.g. in factories 

- Can work 24/7, 365 

Can be used in dangerous environments - e.g. after natural disasters, warzones on recovery missions 

- Can solve problems humans can’t due to large processing capabilities - scientific advancements to benefit humanity

## Disadvantages:

- Safety (e.g. Terminators, military drones etc) 

- Loss of jobs (robots replacing us) 

- Increased wealth inequality (low-skilled jobs might be largely replaced) 

- Environmental issues – materials required for electronics have to be sourced and disposed of 

- Only a limited supply of resources used to create these electornics
