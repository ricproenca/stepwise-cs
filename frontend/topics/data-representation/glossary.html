A

ASCII (American Standard Code for Information Interchange)

A 7-bit character encoding standard that assigns a unique binary code to 128 characters, including English letters, digits, punctuation, and 32 control codes.

A table that maps every keyboard character to a 7-digit binary number.

Example: The character 'A' is assigned the code 65 in denary (0100 0001 in binary).

Don't confuse: ASCII uses 7 bits (128 characters); extended ASCII uses 8 bits (256 characters); Unicode uses a minimum of 16 bits and covers all world languages. ASCII is not a standardised subset of extended ASCII — the extra 128 codes vary by implementation.

1.1.5

B

Binary (number system)

A base-2 number system that uses only the digits 0 and 1; each digit position represents an increasing power of 2 moving from right to left.

The number language computers use, where every value is built from 0s and 1s.

Example: The denary value 13 is represented as 1101 in binary (8 + 4 + 0 + 1).

1.1.2

Binary-Coded Decimal (BCD)

A number system that represents each individual denary digit as a separate 4-bit binary code; only the codes 0000 to 1001 (representing digits 0–9) are valid.

Each decimal digit gets its own 4-bit binary code, rather than converting the whole number to binary at once.

Example: The denary number 964 in BCD is 1001 0110 0100 (9 → 1001, 6 → 0110, 4 → 0100).

Don't confuse: BCD and pure binary produce different bit patterns for the same denary value. BCD of 27 is 0010 0111 (two separate 4-bit groups); pure binary of 27 is 00011011 (a single 8-bit value). The same 8-bit pattern 00100111 is 27 in BCD but 39 in unsigned binary.

1.1.2 1.1.4

Bit

A single binary digit; the smallest unit of data in a computer, holding the value 0 or 1.

The most basic unit of computer information — one switch that is either off (0) or on (1).

Example: The binary number 1011 contains four bits.

1.1.2

Byte

A group of 8 bits, treated as the fundamental unit of computer memory addressing.

A group of eight binary digits; large enough to store a single ASCII character.

Example: The ASCII code for 'Z' (90 in denary) is stored as one byte: 01011010.

1.1.1

C

Character Set

A standardised mapping that assigns a unique binary code to every character, symbol, or control sequence recognised by a computer system.

An agreed list that tells every computer how to translate between characters and the binary numbers stored in memory.

Example: In the ASCII character set, the letter 'a' maps to binary code 1100001 (97 in denary).

1.1.5

E

Extended ASCII

An 8-bit extension of the ASCII standard that uses an additional bit to provide 256 unique character codes, adding accented letters, currency symbols, and drawing characters beyond the original 128.

A wider version of ASCII that adds 128 extra characters for non-English Western European letters and symbols.

Example: The pound sign (£) is code 156 in one common extended ASCII implementation.

Don't confuse: Extended ASCII adds 128 codes beyond standard ASCII but lacks standardisation across implementations; Unicode provides a single universal standard covering all languages.

1.1.5

G

Gibibyte (GiB)

A binary unit of data storage equal to 2³⁰ bytes (1,073,741,824 bytes), defined by the IEC binary prefix system.

Approximately one billion bytes, measured using powers of 2 rather than powers of 10.

Example: A computer with 8 GiB of RAM contains 8 × 2³⁰ = 8,589,934,592 bytes of memory.

Don't confuse: 1 GiB = 2³⁰ bytes (≈1.07 × 10⁹); 1 GB = 10⁹ bytes. A hard drive advertised as "1 TB" contains fewer bytes than "1 TiB" of RAM.

1.1.1

H

Hexadecimal

A base-16 number system that uses the digits 0–9 and the letters A–F to represent values 0–15, where each single hexadecimal digit corresponds to exactly four binary bits.

A shorthand for binary that groups four bits into one digit, making long binary values easier for humans to read and write without error.

Example: The 8-bit binary value 1011 0101 is written as B5 in hexadecimal (1011 = B = 11; 0101 = 5).

1.1.2 1.1.4

K

Kibibyte (KiB)

A binary unit of data storage equal to 2¹⁰ bytes (1,024 bytes), defined by the IEC as the binary equivalent of the decimal kilobyte.

1,024 bytes — the correct binary-based unit for describing computer memory sizes.

Example: A text file containing 1,024 characters encoded in ASCII occupies exactly 1 KiB.

Don't confuse: 1 KiB = 1,024 bytes (binary prefix); 1 KB = 1,000 bytes (decimal prefix). The distinction matters when calculating RAM or cache sizes precisely.

1.1.1

Kilobyte (KB)

A decimal unit of data equal to 10³ bytes (1,000 bytes), based on the SI prefix system where kilo = 1,000.

One thousand bytes, used in storage device specifications and data transfer rates.

Example: A 500 KB image file contains 500,000 bytes of data.

Don't confuse: Kilobyte (KB) = 1,000 bytes (decimal); kibibyte (KiB) = 1,024 bytes (binary). Operating systems often report file sizes in KiB but display "KB" — a common source of confusion.

1.1.1

M

Memory Dump

The output of the contents of a section of computer memory to a screen or printer, typically displayed in hexadecimal to make the binary data readable.

A snapshot of raw memory contents printed out so a developer can inspect what is stored and find errors.

Example: A memory dump might display address 00A4 containing B5, representing the binary value 10110101.

1.1.4

N

Nibble

A group of 4 bits, representing exactly one hexadecimal digit and one BCD digit.

Half a byte — four binary digits grouped together.

Example: The high nibble of 1011 0101 is 1011 (= B in hex); the low nibble is 0101 (= 5 in hex).

1.1.2

O

One's Complement

A method of representing negative integers in binary by inverting all bits of the positive equivalent; produces two representations of zero and does not support standard binary addition directly.

Flip every bit to get the negative version of a number — but the result has a flaw: there are two ways to write zero.

Example: +72 = 0100 1000; one's complement of −72 = 1011 0111.

Don't confuse: One's complement inverts all bits only; two's complement inverts all bits and adds 1. Two's complement is preferred in hardware because it has a single zero and supports addition without correction.

1.1.2

Overflow

An error that occurs when the result of a binary arithmetic operation exceeds the range of values representable in the number of bits allocated, causing the stored result to be incorrect.

The answer is too large (or too small) to fit in the available bits, so the wrong value is stored.

Example: Adding 82 (01010010) and 69 (01000101) in 8-bit two's complement gives 1001 0111, which is interpreted as −105 — incorrect because 151 exceeds the maximum of +127.

1.1.3

T

Two's Complement

A method of representing both positive and negative integers in binary, where the most significant bit carries a negative weight (−2ⁿ⁻¹) and a negative number is obtained by inverting all bits and adding 1.

The standard way computers store negative numbers — flip all the bits and add one.

Example: The 8-bit two's complement of −45: +45 = 0010 1101 → invert → 1101 0010 → add 1 → 1101 0011.

Don't confuse: Two's complement has only one representation of zero (unlike one's complement or sign-magnitude), and subtraction is performed using the same addition circuit, requiring no special hardware.

1.1.2 1.1.3

U

Unicode

A universal character encoding standard that assigns a unique code point to every character in all major world languages, using a minimum of 16 bits per character and supporting over 143,000 characters.

A worldwide standard that gives a unique number to every letter, symbol, and emoji in every human language.

Example: The Greek letter Ω (omega) has Unicode code point U+03A9, stored as 0000 0011 1010 1001 in binary.

Don't confuse: ASCII uses 7 bits and covers 128 English characters; Unicode uses a minimum of 16 bits and covers all world scripts. The first 128 Unicode code points are identical to ASCII.
